## 12. Non-Functional Requirements (`REQ-NFR-*`)

1. **`REQ-NFR-001` (Zero-Config Local & Live AI Execution)**: All AI pipelines (Brand Kit extraction, 7-stage AI Video Agent, AI Visuals generator, Flow AI polish/translation, and TTS voiceover) MUST work seamlessly both when external API keys (`OPENAI_API_KEY`, `ELEVENLABS_API_KEY`) are provided AND out-of-the-box in local environments using Playwright live URL scraping + deterministic synthesis.
2. **`REQ-NFR-002` (Interactive Canvas Performance)**: The Flow Editor stage, Remotion Video Preview player, 5-track NLE playhead scrubbing, and Visual Canvas Editor MUST maintain 30–60 FPS interaction with `< 50ms` UI state feedback when editing colors, text, or timeline spans.
3. **`REQ-NFR-003` (Responsive & Embeddable Players)**: `/share/*` and `/embed/*` routes MUST render without horizontal scrollbars from `360px` mobile width up to `3840px` 4K displays while keeping all normalized (`0..1`) hotspots and pan-and-zoom boxes aligned.
